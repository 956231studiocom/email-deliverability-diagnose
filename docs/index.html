Score any .eml against the rules that decide inbox vs. spam

Offline, read-only, nothing is ever sent. Standard library only — no pip install.

no networkpython 3.8+MITselftest 8/8

Why

When a campaign lands in spam, the answer is already sitting in your inbox — the Authentication-Results header, the missing List-Unsubscribe, the HTML-only body, the subject with three exclamation marks. Nobody reads it, because the header is forty lines of noise. This tool reads it for you and returns a ranked fix list.

Run it

git clone https://github.com/956231studiocom/email-deliverability-diagnose
python3 scripts/diagnose.py --eml examples/bad-campaign.eml --format md

Real output from the bundled sample — a message built the way most damaged campaigns are built:

- Score: **53/100** (damaged)
- From: growth@mailer.example-co.com | Return-Path: -

**Findings**
- auth_results_missing   no Authentication-Results header
- no_unsubscribe         no List-Unsubscribe header
- no_plain_text          HTML-only message, no text/plain alternative
- subject_punct          subject has repeated ! or $$$
- subject_spamword       subject contains: act now, guarantee
- no_message_id          no Message-ID header

**Fix in this order**
1. Pull the raw header from a real inbox (Gmail: Show original)
2. Add List-Unsubscribe with mailto: and https: one-click
3. Add a text/plain part
4. Use at most one exclamation mark
5. Rewrite the subject without trigger words
6. Let your ESP set Message-ID

What it checks

GroupSignals
AuthenticationAuthentication-Results, SPF / DKIM / DMARC verdicts, Return-Path alignment
ComplianceList-Unsubscribe (mailto + one-click https), List-Unsubscribe-Post
Content riskSubject punctuation and trigger words, text-to-image ratio, HTML-only bodies, link count
HygieneMessage-ID, Date, MIME-Version, malformed charset quoting
StructureMIME tree integrity, missing text/plain alternative, oversized single image
HeadersFrom / Reply-To alignment, display-name spoofing patterns
What it does not do: no DNS lookups, no blocklist queries, no SMTP, no ESP login. There is no send code path in the file — which is why you can run it on a production mailbox export on a locked-down machine.

Getting the raw .eml

  • Gmail — open message → ⋮ → Show original → Download Original
  • Outlook — File → Save As → .eml
  • Apple Mail — File → Save As → Raw Message Source
